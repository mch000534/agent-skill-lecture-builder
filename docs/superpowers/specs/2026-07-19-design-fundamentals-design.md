# 設計入門課程設計

## 課程定位

- 課程名稱：設計入門：從視覺基礎到 UX/UI
- 目標受眾：完全沒有設計基礎的一般學生，以及需要製作簡報與社群內容的職場人士
- 課程長度：6 小時，分為三節，每節 2 小時，不安排休息時間
- 課程目標：讓學員能從使用者、問題與目標出發，運用視覺與體驗設計原則完成海報、PPT、Web 與 App 的基礎設計，並建立可重用的設計規則
- 課程形式：原則說明、錯誤與改善對照、四個獨立練習，以及一個跨媒介整合練習

## 教學策略

採用螺旋式整合。每教一組核心原則，立即套用到一種媒介；後續練習持續重用並加深前面學到的原則。這能降低零基礎學員一次吸收大量理論的負擔，也能避免課程變成四套彼此分離的軟體操作教學。

每個練習均採用以下節奏：

1. 觀察問題
2. 套用原則
3. 動手改版
4. 對照檢查

## 三節課程架構

### 第一節：從問題到視覺

總時長 120 分鐘。

- 設計思維，30 分鐘：使用者、情境、問題、目標與限制
- 視覺基礎，50 分鐘：色彩、字體、留白、對比、對齊與視覺層級
- 海報練習，40 分鐘：整理活動資訊並建立清楚的視覺焦點

### 第二節：從內容到體驗

總時長 120 分鐘。

- 構圖與版面，25 分鐘：閱讀動線、網格、分組與節奏
- PPT 練習，35 分鐘：將資訊密集頁改造成一頁一重點
- UX 與資訊架構，30 分鐘：使用流程、內容分組、導航與可尋性
- Web 練習，30 分鐘：規劃活動首頁架構、內容層級與 CTA

### 第三節：從元件到系統

總時長 120 分鐘。

- UI 基礎，20 分鐘：按鈕、表單、卡片、導航與狀態
- 設計系統，15 分鐘：色彩、字級、間距及元件規則
- App 練習，25 分鐘：設計活動報名流程與關鍵畫面
- 回饋與迭代，15 分鐘：依目標、一致性與可用性評圖
- 跨媒介整合練習，45 分鐘：完成同一活動主題的海報、PPT、Web 與 App 低保真草案

## 獨立練習

### 海報：校園公開講座

- 任務：將散亂的日期、地點、講者及報名資訊重新編排
- 檢核：三秒內看懂主題、資訊層級、對齊與留白

### PPT：專案成果報告

- 任務：將一頁塞滿文字與數據的簡報重新設計
- 檢核：一頁一重點、圖文比例與閱讀順序

### Web：社區工作坊首頁

- 任務：規劃 Hero、活動介紹、流程、FAQ 與報名 CTA
- 檢核：資訊架構、掃讀性與行動路徑

### App：場地預約流程

- 任務：設計選日期、選時段、填資料及確認畫面
- 檢核：流程直覺、表單清楚，以及狀態與回饋

## 跨媒介整合練習

整合練習以「城市創意節」為共同主題。45 分鐘內完成低保真草案與核心規則，而非四份精修作品。

必要產出：

- 一位主要使用者與一個溝通目標
- 一組基本色彩、字體、間距與元件規則
- 一張活動海報
- 一頁簡報主視覺
- 一個 Web 首頁線框
- 一段 App 報名關鍵流程

互評標準：

1. 目標是否清楚
2. 視覺層級是否明確
3. 閱讀與操作是否順暢
4. 跨媒介是否一致
5. 設計決策能否說明理由

## 課程頁內容設計

課程放置於 `lectures/design-fundamentals/`，分類使用「設計印刷」。`content.md` 依三節課分成三個主章節，並使用現有課程元件呈現：

- 左右對照：常見錯誤與改善方式
- 流程元件：設計思維、UX 流程與迭代步驟
- 卡片：色彩、字體、留白、對齊、UI 元件與設計系統規則
- 練習區：任務說明、限制條件與檢查清單
- Quiz：每節的概念判斷與即時回饋
- Summary：結尾設計檢查表與整合任務評分重點

## 視覺教材

建立五張原創 SVG 教學圖，使用相對路徑載入，不依賴外部 CDN：

1. 海報改版前後對照
2. PPT 資訊層級改版
3. Web 首頁內容與閱讀動線
4. App 報名流程與畫面狀態
5. 色彩、字級、間距及元件組成的迷你設計系統

SVG 只使用必要的示意文字，重點放在視覺層級、版面關係與流程，不以裝飾效果取代教學資訊。

## 檔案與建置流程

預計新增或更新：

- `lectures/design-fundamentals/config.yaml`
- `lectures/design-fundamentals/content.md`
- `lectures/design-fundamentals/assets/images/*.svg`
- `lectures/design-fundamentals/index.html`
- `lectures/design-fundamentals/assets/og-image.jpg`
- `lectures/manifest.js`

建置順序：

1. 建立課程目錄與內容
2. 驗證 `content.md` 與 SEO URL
3. 建置 `index.html`
4. 立即產生 OG 縮圖
5. 更新課程清單
6. 重新驗證必要產物、圖片路徑與課程時數

## 驗收標準

- 課程內容使用繁體中文，且不含 Emoji
- 三節課各為 120 分鐘，總長 6 小時
- 完整涵蓋設計思維、視覺基礎、構圖與版面、UX、UI、設計系統、回饋與迭代
- 包含海報、PPT、Web、App 四個獨立練習及一個跨媒介整合練習
- 五張 SVG 教學圖能在建置後的 HTML 中正確顯示
- `validate.mjs` 無錯誤
- `build.mjs` 與 `generate-og.mjs` 成功
- `lectures/manifest.js` 包含新課程，分類為「設計印刷」
