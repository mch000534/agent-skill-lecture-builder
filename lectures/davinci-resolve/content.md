# 介面總覽：六大頁面全解析
> DaVinci Resolve 的設計理念是「每個工作階段都有專屬空間」——理解頁面分工是入門關鍵

## 六大工作頁面

### 🎯 頁面快速導覽

[flow]
1. Cut（快剪）— 適合快速粗剪，雙時間軸設計，直覺高效
2. Edit（精剪）— 傳統剪輯介面，完整控制所有軌道與效果
3. Fusion（特效）— 節點式視覺特效與動態圖形製作
4. Color（調色）— 業界頂級調色工具，節點式色彩管理
5. Fairlight（音頻）— 專業音頻混音與後製
6. Deliver（交付）— 輸出設定與格式轉換
[/flow]

## Cut 快剪頁面

### ✂️ Cut 頁面的設計邏輯

Cut 頁面為快速剪輯而生，上方為縮圖時間軸（全片鳥瞰），下方為精確時間軸：

- **雙時間軸** 設計：上方拖動快速定位，下方精確剪輯
- 素材直接從「媒體資料庫」拖入即可開始剪輯
- 適合新聞、Vlog、社群短片等需要快速交片的場景
- 智慧插入（Smart Insert）：自動找到最近的剪切點插入素材

## Edit 精剪頁面

### 🎞️ Edit 頁面：完整的剪輯掌控

Edit 頁面是傳統 NLE（非線性剪輯）的標準排列方式：

```prompt [label="Edit 頁面三大區域"]
左上：媒體資料庫 / 效果庫
右上：檢視器（來源 + 時間軸）
下方：時間軸（多軌道剪輯區）
```

- 支援無限影片與音頻軌道
- 關鍵影格動畫（Keyframe）控制所有參數
- 速度調整：快放、慢動作、倒播
- 嵌套時間軸（Nested Timeline）：複雜項目模組化管理

> **初學者建議從 Edit 頁面開始**
> Cut 頁面雖然快速，但 Edit 頁面的介面與業界其他軟體（Final Cut Pro、Premiere）更相似，學習 Edit 頁面的概念可以更容易遷移到其他軟體的知識。

# 基本剪輯工作流程
> 從素材導入到粗剪完成，建立正確的工作習慣比學會快捷鍵更重要

## 第一步：建立專案與導入素材

### 📁 專案管理最佳實踐

[flow]
1. 新增專案 — 在專案管理頁面點「+」建立新專案，給予清晰的命名
2. 設定時間軸格式 — 根據拍攝規格設定：解析度（1080p / 4K）、幀率（24 / 30 / 60fps）
3. 建立媒體資料夾 — 在媒體資料庫建立分類資料夾：A-Roll、B-Roll、音樂、音效
4. 導入素材 — 拖曳媒體資料夾到媒體資料庫，或使用「檔案 → 導入媒體」
5. 整理素材 — 為重要素材加上旗標、顏色標記或關鍵字
[/flow]

```prompt [label="時間軸格式建議（社群影片）"]
解析度：1920 × 1080（Full HD）
幀率：30fps（適合日常影片）
     24fps（適合電影感作品）
色彩空間：Rec.709（一般攝影機）
音頻：48kHz / 24-bit
```

## 第二步：粗剪（Rough Cut）

### 🎬 有效率的粗剪策略

粗剪目標是**確認結構與節奏**，不要在細節上浪費時間：

- 先選取最好的鏡頭（Primary Selects），刪除明顯失誤的鏡頭
- 按照腳本或故事板排列主要畫面（A-Roll）
- 不用追求完美，先把故事說完整
- 粗剪完成後，全片審視整體節奏感

### ✂️ 常用剪輯工具

[tags]
- [blue] 選取工具（A）：移動、調整素材長度
- [orange] 刀片工具（B）：在任意位置切割素材
- [green] 修剪工具（T）：Ripple Edit，剪短不影響後續素材位置
- [purple] 滑動工具（S）：調整素材在時間軸的位置，不影響總長度
[/tags]

## 第三步：精剪與 B-Roll 插入

### 🎯 精剪重點技巧

### 🎵 音頻引導剪輯法
- 音頻（對白/音樂）的節奏決定剪輯點
- 對白結束前半拍切入下一畫面，讓節奏更流暢
- 音樂的鼓點、強拍是天然的剪輯點

### 🎞️ J-Cut 與 L-Cut

```prompt [label="J-Cut vs L-Cut 說明"]
J-Cut（先聲奪人）：
  下一個鏡頭的音頻比畫面早出現
  → 帶出期待感，常用於場景轉換

L-Cut（餘音繞梁）：
  上一個鏡頭的音頻延伸到下一個畫面
  → 保持情感連續性，避免生硬跳接
```

> **B-Roll 是影片質感的關鍵**
> A-Roll 是主要畫面（主播說話、訪談），B-Roll 是補充畫面（環境、特寫、過場）。
>
> 優秀的 B-Roll 不只填補畫面空缺，更能強化情緒、提供視覺資訊。每拍攝 1 分鐘 A-Roll，建議準備至少 3-5 分鐘的 B-Roll 素材。

# Color 調色：從平淡到電影感
> 調色不是濾鏡，是對畫面情緒的精確控制——DaVinci Resolve 的調色功能是業界標準

## 調色基礎概念

### 🎨 調色的兩個階段

[flow]
1. 一級調色（Primary Correction）— 修正曝光、白平衡等基本問題，讓畫面「正確」
2. 二級調色（Secondary Correction）— 選取特定顏色或區域，創造獨特的視覺風格
[/flow]

### 📊 看懂示波器（Scopes）

調色必學工具——示波器是客觀的顏色測量儀器：

[tags]
- [blue] Parade（分量圖）：分別顯示 R / G / B 三個通道的亮度分布
- [orange] Waveform（波形圖）：顯示畫面從左到右的亮度變化
- [green] Vectorscope（向量圖）：顯示畫面的色調與飽和度分布
- [purple] Histogram（直方圖）：顯示整體亮度分布，判斷曝光是否正確
[/tags]

## 節點系統（Node System）

### 🔗 節點是 DaVinci Resolve 調色的核心

```prompt [label="節點工作流程示意"]
串聯節點（Serial Node）：
  [節點 1：一級調色] → [節點 2：膚色修正] → [節點 3：風格化]

並聯節點（Parallel Node）：
  用於混合不同調色結果，精確控制各層強度

圖層節點（Layer Node）：
  類似 Photoshop 圖層，下方節點蓋住上方節點
```

- 每個節點獨立處理，可個別開關、調整強度
- 建議為每個節點加上標籤（右鍵 → 標籤），便於管理複雜調色
- 儲存為「靜態」（Still）可快速對比調色前後效果

## 調色工具實戰

### 🎛️ Lift / Gamma / Gain（LGG 色輪）

三個色輪分別控制畫面不同亮度區域的色調：

[tags]
- [blue] Lift（暗部）：控制陰影區域的色調，常加入冷色調增加層次感
- [orange] Gamma（中間調）：控制中間亮度的色調，影響整體觀感最大
- [green] Gain（亮部）：控制高光區域的色調，常加入暖色調增加質感
- [purple] Offset（全域偏移）：整體偏移所有亮度的色調
[/tags]

### 🌅 打造電影感的調色配方

```prompt [label="電影感調色步驟（Orange & Teal 風格）"]
步驟 1：一級調色
  - Lift 微微往藍色偏（陰影變冷）
  - Gain 微微往橘黃色偏（高光變暖）
  - 確認示波器 Parade 中 R/G/B 無過曝

步驟 2：膚色保護
  - 使用「限定器」選取膚色範圍
  - 將膚色偏往橘色（Orange & Teal 的 Orange）

步驟 3：降低飽和度
  - 整體飽和度降至 40-60（Saturation）
  - 增加對比度（Contrast 0.05-0.15）

步驟 4：加入暈影（Vignette）
  - Power Window 繪製橢圓形
  - 反向選取，邊緣降低曝光 -0.3 至 -0.5
```

> **調色要「看示波器，不要只看螢幕」**
> 不同顯示器的色彩校準各不相同，相同的影片在不同螢幕上看起來可能差異極大。
>
> 養成看示波器的習慣，讓數據告訴你畫面的客觀狀態，才能確保影片在各種設備上都正確呈現。

# Fairlight 音頻：讓聲音和畫面一樣專業
> 好的影片，音頻佔了一半的質感——觀眾可能原諒畫質差，但絕對無法忍受爛音質

## 音頻基礎設定

### 🎙️ 音頻軌道類型

[flow]
1. 對白（Dialogue）— 主要人聲，需要最清晰的處理
2. 音效（Sound FX）— 環境音、動作音效，增加臨場感
3. 音樂（Music）— 背景音樂，設定情緒基調
4. 混音（Mixdown）— 最終輸出的主軌道
[/flow]

## 人聲處理三步驟

### 🔊 讓人聲清晰的關鍵處理

### 🎚️ 降噪（Noise Reduction）

```prompt [label="Fairlight 降噪操作步驟"]
1. 找到一段純背景噪音（沒有說話的片段）
2. 右鍵選取 → 「分析音頻」→「雜訊輪廓」
3. 在效果庫找「降噪」插件，載入噪音輪廓
4. 調整降噪強度（建議從 50% 開始，避免過度處理）
5. 對比效果：過度降噪會產生「金屬感」的機器聲
```

### 📊 均衡器（EQ）基本設定

[tags]
- [blue] 低頻截斷（High-pass Filter）：80-120Hz 截斷，去除低頻隆隆聲
- [orange] 中低頻（200-500Hz）：若聲音「悶」可微微衰減
- [green] 中頻存在感（1-3kHz）：適度提升，讓人聲更清晰有力
- [purple] 高頻空氣感（8-12kHz）：微微提升，增加人聲的「通透感」
[/tags]

### 🎯 壓縮器（Compressor）設定

壓縮器的作用是縮小音量的動態範圍，讓聲音更穩定：

```prompt [label="人聲壓縮建議設定"]
Threshold（閾值）：-18 至 -12 dB（聲音超過此值才壓縮）
Ratio（壓縮比）：3:1 至 4:1（對每 3-4dB 超出，壓縮回 1dB）
Attack（起音）：5-10ms（反應速度，太快會壓掉輔音）
Release（釋音）：60-100ms（壓縮結束後恢復正常速度）
Make-up Gain：補回壓縮損失的音量
```

## 音量標準化

### 📢 影片音量標準

[flow]
1. 對白目標音量 — -12 至 -6 dBFS（LUFS 約 -16 至 -14）
2. 背景音樂音量 — 比對白低 15-20 dB
3. 音效音量 — 根據情境調整，不蓋過對白
4. 最終混音 — 整體峰值不超過 -3 dBFS，避免破音
[/flow]

> **YouTube 和社群平台的音量標準**
> YouTube 會自動將影片音量正規化到 -14 LUFS，若你的影片太響會被調低，太安靜也會被調高但可能帶入更多雜訊。
>
> 建議最終輸出前在 Fairlight 的「響度計」（Loudness Meter）確認整體 LUFS 值，讓聲音在平台上呈現最佳狀態。

# Deliver 交付：選對格式，讓影片完美呈現
> 剪輯再好，輸出設定錯誤就前功盡棄——了解格式差異讓你避開最常見的坑

## 交付頁面基本操作

### 📤 Deliver 工作流程

[flow]
1. 進入 Deliver 頁面 — 點擊底部「火箭」圖示
2. 選擇輸出範圍 — 整條時間軸或設定 In / Out 點
3. 選擇輸出預設 — YouTube、Vimeo、自訂格式等
4. 設定輸出路徑 — 選擇儲存資料夾與檔案名稱
5. 加入輸出佇列 — 點「加入至渲染佇列」
6. 開始渲染 — 點「全部渲染」，等待輸出完成
[/flow]

## 常用輸出格式

### 🎯 不同用途的輸出建議

[tags]
- [blue] YouTube / 社群平台：H.264 / H.265，1920×1080 / 3840×2160，品質 80%+
- [orange] 存檔備份：ProRes 422 HQ（macOS）/ DNxHR（Windows），高品質但檔案大
- [green] 客戶交片：H.264 MP4，約 20Mbps，普遍相容性最佳
- [purple] 繼續後製：DaVinci Resolve 專案（.dra）或 XML 格式匯出
[/tags]

```prompt [label="YouTube 最佳輸出設定"]
格式：MP4（H.264）或 MKV（H.265）
解析度：1920×1080（Full HD）或 3840×2160（4K）
幀率：與拍攝幀率相同（24 / 30 / 60fps）
碼率：VBR，目標 20Mbps（1080p）/ 50Mbps（4K）
音頻：AAC，320kbps，48kHz，立體聲
```

### 🎬 輸出常見問題排查

- [x] 影片輸出後顏色偏暗 → 確認色彩空間選擇「Rec.709」，並開啟「色彩空間轉換」
- [x] 輸出後影片很大 → 調低碼率或改用 H.265 格式（同品質檔案小約 40%）
- [x] 輸出後音頻不同步 → 檢查音頻取樣率是否全程統一（建議 48kHz）
- [x] 渲染速度很慢 → 在專案設定開啟「GPU 加速」，確認顯卡驅動是最新版本

# 實作練習：拍攝你的第一支短片
> 理論學再多不如動手做——用最簡單的題材，完整走一遍剪輯流程

## 30 秒短片挑戰

### 🎥 題目：「我的一天」Vlog 片段

適合初學者的練習題材，因為素材容易取得：

[flow]
1. 拍攝 — 用手機拍攝 3-5 個日常場景，每個場景 30-60 秒
2. 導入素材 — 建立新專案，將手機影片導入媒體資料庫
3. 粗剪 — 從每個場景挑選最好的 5-10 秒，排列成 30 秒故事
4. 音樂 — 加入一首節奏感相符的背景音樂（建議使用無版權音樂）
5. 調色 — 套用統一的色調，讓不同場景的畫面風格一致
6. 輸出 — 以 YouTube 格式輸出 MP4
[/flow]

### ✅ 自我評估清單

- [x] 時間軸整齊，素材都在正確的軌道（影片/音頻分開）
- [x] 沒有意外的黑色空白或靜音片段
- [x] 音樂音量不會蓋過說話聲
- [x] 開頭 3 秒內有吸引人的畫面（不要從靜止畫面慢慢開始）
- [x] 結尾有自然的收尾，不要突然硬切黑幕
- [x] 輸出的 MP4 可以在手機上順利播放

> **不要追求完美，先求完成**
> 第一支影片不需要是傑作。最重要的是完整走一遍流程：拍攝 → 剪輯 → 調色 → 輸出。
>
> 每走一遍，你就會發現哪個環節最需要加強。持續練習，進步的速度遠比反覆觀看教學影片來得快。
