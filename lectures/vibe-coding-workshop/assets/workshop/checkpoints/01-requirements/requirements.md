# 待辦清單應用需求

## 問題與成功定義

### 使用者

主要使用者是想在個人瀏覽器中快速整理短期工作的一般使用者。使用者能操作表單與按鈕，但不應被要求建立帳號、設定伺服器或理解資料格式。

### 情境

使用者在自己的桌上型或行動裝置瀏覽器開啟頁面，記下當下要完成的事項，並在工作過程中更新狀態。使用者可能關閉或重新載入頁面，之後仍希望繼續查看同一裝置中的清單。

### 問題

零散事項容易遺漏，純文字清單又不容易區分完成狀態。若沒有簡單且可持續保存的清單，使用者會重複確認、忘記工作，或無法專注於尚未完成的項目。

### 成功結果

使用者可以新增、完成、取消完成、篩選及刪除待辦事項。每次成功變更都保存在目前瀏覽器；重新載入後內容與完成狀態一致。無效輸入或儲存失敗會出現清楚訊息，且不會讓既有資料或畫面進入錯誤狀態。

## 使用者故事

身為需要整理短期工作的一般使用者，當我在自己的裝置規劃與執行工作時，我想要建立、更新、篩選及刪除待辦事項，以便專注在仍需完成的工作，並在重新載入頁面後延續進度。

## Given/When/Then 驗收條件

### 新增待辦

- Given 使用者已開啟頁面，且標題欄輸入 `準備會議資料`
- When 使用者送出新增表單
- Then 清單新增一筆標題為 `準備會議資料`、狀態為未完成的待辦，輸入欄清空，資料成功保存在目前瀏覽器

### 完成待辦

- Given 清單中有一筆未完成的 `準備會議資料`
- When 使用者啟用該筆待辦的完成控制
- Then 該筆待辦顯示為已完成，並保存新的完成狀態

### 取消完成

- Given 清單中有一筆已完成的 `準備會議資料`
- When 使用者再次啟用該筆待辦的完成控制
- Then 該筆待辦恢復為未完成，並保存新的完成狀態

### 全部篩選

- Given 清單同時有已完成與未完成項目
- When 使用者選擇「全部」
- Then 畫面顯示所有項目，資料本身不被改寫

### 未完成篩選

- Given 清單同時有已完成與未完成項目
- When 使用者選擇「未完成」
- Then 畫面只顯示未完成項目，已完成資料仍保留

### 已完成篩選

- Given 清單同時有已完成與未完成項目
- When 使用者選擇「已完成」
- Then 畫面只顯示已完成項目，未完成資料仍保留

### 刪除待辦

- Given 清單中有一筆 `準備會議資料`，且另有其他待辦
- When 使用者啟用該筆待辦的刪除控制
- Then `準備會議資料` 從畫面與本機儲存資料移除，其他待辦保持不變

### 重新載入

- Given 使用者已成功新增、切換或刪除待辦
- When 使用者重新載入頁面
- Then 畫面還原最後一次成功保存的待辦內容與完成狀態

## 功能與資料規則

- 待辦標題必須是字串，先以 `trim()` 移除頭尾空白，再以 JavaScript `string.length` 計算 UTF-16 code units。
- 正規化後的標題長度必須為 1 至 120；長度 120 接受，長度 121 拒絕。
- 空白、超長或錯誤型別輸入不得新增資料，也不得改變既有資料。
- 每筆待辦具有唯一識別碼、正規化標題與布林完成狀態。
- 篩選只改變顯示結果，不刪除、不重排也不改寫原始清單。
- 空清單與篩選後沒有符合項目時，畫面應提供可理解的空狀態。

## 本機資料與失敗處理

- 所有資料僅保存在目前瀏覽器的 localStorage，不傳送至伺服器或第三方服務。
- localStorage 內容一律視為不可信資料；載入前驗證資料結構、欄位型別、標題限制、識別碼格式與唯一性。
- localStorage 不可用、讀取拋錯、內容損壞、序列化失敗或寫入失敗時，介面以 `aria-live` 區域顯示可理解的警告，應用程式仍可操作且不得崩潰。
- 新增、切換或刪除先更新當前記憶體狀態與畫面，再嘗試寫入 localStorage；寫入失敗時不得回滾，當前操作與畫面變更仍有效。
- 寫入失敗時不在畫面宣稱變更已保存，並顯示 `目前變更不會在重新整理後保留。`；重新載入後只會還原最後一次成功保存的狀態。

## 安全與可存取性

- 使用者輸入及儲存內容只透過 `textContent` 呈現，不使用會解析不可信 HTML 的 API。
- 輸入中的標籤、事件屬性與腳本必須顯示為純文字，不能執行。
- 所有操作可用鍵盤完成，焦點清楚可見；按鈕具有可辨識文字，動態錯誤與儲存警告可由輔助技術得知。
- Agent 遵循最小權限，只讀寫本工作坊核准目錄；未經明確授權不安裝套件、不讀寫專案外資料、不刪除既有成果、不發布、不推送也不變更權限。
- 實作與測試只使用 Node.js 與瀏覽器內建能力，不新增第三方依賴。

## 非目標

本次交付不包含：

1. 帳號、登入、多人共享或跨裝置同步。
2. 後端資料庫、雲端 API、遙測或分析服務。
3. 到期日、提醒、標籤、排序、拖放、搜尋或重複事項。
4. 離線安裝、推播通知或原生行動應用程式。
5. 匯入、匯出及不同瀏覽器之間的資料搬移。
