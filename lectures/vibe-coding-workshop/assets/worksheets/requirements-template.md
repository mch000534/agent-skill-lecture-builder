## 四、非功能與安全需求

### 輸入限制

- [ ] 標題只接受字串並移除頭尾空白；`trim()` 後長度以 JavaScript `string.length` 計算，即 UTF-16 code units，必須介於 1–120
- [ ] 依同一個 `string.length` 計算方式，長度 120 成功，長度 121 失敗且不改變既有資料
- [ ] 空白標題、超長標題或錯誤型別不會改變既有資料
- 補充限制：________________________________________________________________

### 不信任資料

- [ ] 使用者輸入與 localStorage 內容一律視為不可信資料
- [ ] 畫面只用安全 DOM API 與純文字呈現，不解析輸入中的 HTML 或事件屬性
- [ ] 載入資料時驗證物件欄位、UUID、標題、布林值與 ID 唯一性

### 儲存失敗

- [ ] localStorage 不可用、資料損壞、序列化失敗或寫入失敗時，應顯示可理解的錯誤
- [ ] 新增、切換或刪除的寫入失敗時，當前記憶體操作與畫面變更仍有效，不回滾到先前狀態
